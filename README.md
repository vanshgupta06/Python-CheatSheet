# Python-CheatSheet
A floating, searchable, always-handy Python reference card built with Tkinter.

## Features
- Instant search across name, description, code, and LeetCode notes
- Category dropdown filter
- Two-pane layout: browsable list (left) + detail viewer (right)
- One-click code copy
- Add your own custom snippets (saved to disk between sessions)
- Pin-to-top toggle + draggable frameless-style title bar
- Covers Python basics and every built-in function

## Requirements
- Python 3.x
- Tkinter (usually included with Python; on Linux you may need `sudo apt install python3-tk`)

## Usage
Use the search bar to filter entries, or pick a category from the dropdown. Click any entry in the list to view its description and example syntax. Use the copy button to grab code snippets, or add your own custom entries via the "Add" dialog — they'll persist across sessions.

## Keyboard Shortcuts
- `↑` / `↓` — Navigate between entries
